# BART＋状态空间研究

毕业论文的可复现实验仓库：在**美国国债收益率曲线**和**空气质量传感器在线校准**两个场景中，分别检验宏观／传感器非线性、潜在状态联合估计和动态校准的作用。

研究假设与文献边界见 [中文研究说明](docs/research_ideas.md)，实际运行结果及局限见 [首轮实验报告](docs/first_round_results.md)。模型组合本身不被预先认定为创新；代码正确、链已收敛和假设得到支持是三个不同的判断。

## 快速开始

在仓库根目录运行，支持当前 Debian 13 x86-64 云环境，无需 root：

```bash
bash scripts/install.sh
python3 scripts/run.py prepare
python3 scripts/run.py test
python3 scripts/run.py experiment --config configs/air_pilot.json
python3 scripts/run.py experiment --config configs/yield_pilot.json
python3 scripts/run.py report artifacts/具体运行目录 --output results/generated_summary.md
```

所有 R 命令通过 `scripts/Rscript` 执行。R 4.5.0、dbarts、posterior 等版本由 `renv.lock` 固定；运行时下载来源和 SHA-256 由 `renv/runtime-sources.json` 固定，详情见 [运行时说明](renv/README.md)。没有需要常驻的服务。云任务已经隔离，沿用现有 checkout，无需另建 worktree。

已有数据缓存时用 `python3 scripts/run.py prepare --offline`，不会访问网络。默认安装和下载保留 TLS、签名／校验和验证。数据快照更新必须显式更新来源及校验值，不能为了下载成功关闭验证。

## 实验命令与输出

`scripts/run.py` 提供 `prepare`、`test`、`experiment`、`report` 四个入口。配置文件使用 JSON，常用推断参数为 `chains`、`burn`、`draws`、`trees`、`seed`；`phase` 必须为 `exploratory`。`simulation_air.json` 与 `simulation_yield.json` 运行模拟；`air_pilot.json` 与 `yield_pilot.json` 运行小规模真实数据验证。

每次运行生成独立的 `artifacts/` 目录，包含：

- 配置、Git commit、未提交状态、实际源码快照与哈希、数据版本及运行时版本。
- 完整日志、耗时、退出状态；失败和部分完成的运行也保留。
- 预测对象、逐观测评分、汇总评分、多链诊断及停测掩码。

短链 pilot 用于验证管线并估计计算成本。**当前两个场景的首轮及已完成的延长运行中，关键贝叶斯模型尚未满足全部预设收敛阈值，不能据评分认定创新有效。**正式解释前须检查关键抽样量的 Rhat < 1.01、bulk/tail ESS ≥ 400；固定的插件参数没有 MCMC 诊断，不应伪装成通过诊断的后验。报告器会区分这些情况，少量时间块不会给出假精确的 bootstrap 区间；最新运行状态以首轮实验报告为准。

新运行同时诊断参数／训练函数、代表位置的条件预测均值及预测观测抽样；代表位置的诊断不意味着整个函数曲面都已收敛。早期运行没有预测量诊断，不能被新版报告追认为完整通过。独立混合审计用 `scripts/Rscript scripts/audit_mixing.R` 重跑，自行生成固定种子的模拟数据，不依赖旧运行目录。

已导出的图表与小型账本见 [首轮结果存档](results/first_round/)。`python3 scripts/plot_results.py` 根据记录的固定 run ID 重新导出；只有重绘 PNG／SVG 需要 [可选 Python 绘图依赖](requirements-plots.txt)，当前云实例已验证这些版本。新机器可在专用虚拟环境中使用 `python -m pip install -r requirements-plots.txt` 安装；核心实验和 Markdown 报告不依赖这些包。原始运行目录保留在云工作区，另一个新 checkout 必须先重跑相应配置并明确更新导出选择，或者恢复已有运行存档，才能重建这些图。

## 数据与信息边界

| 场景 | 数据和时间切分 | 当前限制 |
|---|---|---|
| 收益率 | GSW 六个零息期限；1985—2004 初始训练、2005—2019 探索、2020—2024 封存 | 官方 GSW／FRED 下载后锁定快照；使用修订后的历史值，因此是伪样本外实验 |
| 空气质量 | UCI CO 参考值与五传感器＋温湿度；训练至 2004-10，验证 2004-11—12，2005 数据封存 | 单地点约一年数据；潜在偏差不等于已识别的物理老化 |

Fed、FRED 与 UCI 的官方文件现均已取得并校验。GSW 是美联储研究人员的研究数据产品，不能等同于官方统计发布。当前默认使用原计划中的总工业产能利用率 **TCU**，收益率研究面板为 1985—2024 年的 480 个月。网络更新前曾运行的制造业 **CUMFNS** 镜像 pilot 单独保留，不与官方 TCU 运行混合。宏观变量按预测目标月份滞后两个月，CPI 使用对数同比；这不消除历史数据修订造成的前视风险。收益率为年化百分数，NS 期限为月，载荷参数为 0.0609/月。官方实时下载地址未来可能更新；校验值变化时程序会要求显式更新快照，已缓存版本可离线复现。

空气质量 `-200` 转为缺失，完整小时网格保留。其他 `(GT)` 参考仪器列不作为特征。24／72／168 小时的人工停测之间至少留 24 小时可重新校准区间；只给原本有真值的时点评分。测试期仅向前过滤，参数抽样固定且等权，因此不宣称完整序贯参数贝叶斯更新。传感器输入缺失的时点跳过预测评分及观测更新。

封存段可由数据准备程序存档，但实验入口拒绝使用其标签做拟合、调参或评分。未来如启用确认实验，须先明确锁定研究协议并记录确认集的使用。

## 模型与推断

收益率包括随机游走、完整 VAR 的两阶段 DNS、联合线性 DNS、线性宏观 DNS、匹配的两阶段宏观 BART 和联合 BART M0。完整 VAR 基线为插件估计，其余模型的动态约束与后验处理并不完全相同，不能把全部差异归因于非线性。两阶段 BART 是本项目的匹配对照，不是含随机波动等结构的原始 BAVART 的精确复刻；宏观条件持续性 M1 尚未实现。

空气质量包括静态 BART、线性校准＋AR(1)、固定 BART 后验均值＋残差 AR(1)、联合 BART＋AR(1)，首轮固定 rho=0.99。两阶段空气模型不传播第一阶段函数不确定性，因此与联合模型的差异同时涉及不确定性传播和反馈。函数与缓慢变化的偏差状态可能相互补偿；零均值状态先验提供锚定，但并不保证有限样本下可以清楚识别二者。

共用 Kalman／FFBS、保持先验尺度不变的持久化 dbarts 接口及预测评分。树的分裂输入不含未知潜在状态，保留精确的条件线性高斯状态更新；MF-BAVART 原文对未知状态进入非线性函数的情形使用线性 effect-size 近似后再做 FFBS，两者模型结构不同，不能直接推断精度优劣。收益率首版只支持每个月至少三个可识别期限的初始化；整月无收益率的情形尚未实现。

## 开发与复现

在研究分支上按可检查的阶段提交代码，通过 PR 记录变化；`main` 保持稳定。源码、配置、锁文件、来源清单和小型研究摘要进入 Git；原始数据、运行时、后验样本和缓存不进入 Git。比较实验时检查配置和源码哈希，避免把修改前后的运行混在同一个结果中。
